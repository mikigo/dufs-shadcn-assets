Get started in seconds

Download the latest release, extract, and run.

# 1. Download the latest release from GitHub
#    https://github.com/mikigo/dufs-shadcn-assets/releases

# 2. Extract to your assets directory
unzip dufs-shadcn-assets.zip -d ./assets

# 3. Start dufs with the custom theme
./dufs ./serve-path -A --assets ./assets

# 4. Open http://localhost:5000

Configuration

// assets/config.json
{
  "logo_text": "My File Server",
  "logo_size": "32px",
  "logo_text_font_size": "18px",
  "view_mode": "icons"
}
